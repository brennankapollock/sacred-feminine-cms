# Keeping an Event Unpublished in Sanity

Your events stay visible on the website only after they are **published** in Sanity. If you’d like to keep an event saved but hidden from the site, follow these steps:

1. In Sanity Studio, open the event you want to hide.
2. Click the **Unpublish** button in the top-right corner. Confirm the prompt.
3. The document moves back into **Draft** status. Drafts are saved, editable, and restorable at any time, but they do not appear on the website.

When you are ready for the event to go live again, open the draft and press **Publish**.

### Optional: keep the event visible but close ticket sales

If you need the event card to stay on the site but want to prevent new purchases, simply toggle off **Enable Checkout** (or **Show Ticket Button**) inside the event’s “Checkout” section. This hides the “Get Tickets” button while leaving the rest of the event details visible.
